## Running the Project

Clone the repository:

```bash
git clone https://github.com/jeet-biswas-09/RanChat.git
```

Go into the Project Folder:

```bash
cd RanChat
```

Install dependencies:

```bash
npm install
```

Start the Expo development server:

```bash
npx expo start
```

The project can then be opened using Expo Go or an appropriate development build.

## Firebase Configuration

RanChat uses Firebase for authentication and other application functionality.

The Firebase configuration file is intentionally not included in the public repository.

To run the project with your own Firebase project, configure the required Firebase credentials according to your development environment.

I have liked computers, coding and development for a long time, and I wanted to build something of my own.

A lot of what I know about development now, I learned while building this project.
